# Gem TD Grass Renderer

Grass clump geometry is authored in `Geometry` and rendered from baked,
package-owned `Mesh` assets.

1. Select a clump definition under `Geometry`.
2. Edit **Profile Rows** and **Blades** in the Inspector.
3. Click **Bake Mesh**.
4. Inspect the result in Play Mode.

The output target is shown read-only. Default A/B definitions always bake to
their canonical package meshes; a new user-created definition derives a
deterministic sibling output on its first bake. Bake and output-assignment
changes support Unity Undo.

Geometry cost:

- `vertices = blades × profileRows × 2`
- `indices = blades × (profileRows - 1) × 6`

Use **Gem TD > Grass > Bake All Package Clump Meshes** to bake every package
definition. Geometry is never regenerated by `OnValidate` or at runtime.
